# Evaluation Skill

> 用途：定义 JobAgent 的评估规则，确保输出可靠、结构化、真实、可执行。

## 评估目标

JobAgent 的输出必须满足：

- 格式稳定。
- 事实一致。
- 不编造简历经历。
- 建议具体可执行。
- 能帮助用户改简历、准备面试和制定行动计划。

## 核心检查项

1. Schema 是否正确。
2. 输出是否基于用户简历和 JD。
3. 是否编造了用户经历。
4. 匹配分是否有证据支撑。
5. 建议是否具体可执行。
6. 简历优化是否比原文更清晰、更岗位相关。
7. 项目追问是否能暴露真实短板。
8. 端到端流程是否能跑通。

## 推荐测试

- 单元测试：schema、parser、service。
- 集成测试：简历 + JD -> 报告。
- Golden cases：固定样例对比输出质量。
- LLM-as-judge：后期评估建议质量和事实一致性。

## 人工验收标准

- 用户输入一份简历和一份 JD 后，能得到完整 Markdown 报告。
- 报告包含匹配分、优势、短板、优化建议和项目追问。
- 报告没有凭空增加用户经历。
- 输出能指导用户马上修改简历或准备面试。
