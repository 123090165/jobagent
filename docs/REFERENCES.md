# References

> 用途：记录参考资料、借鉴点和明确不借鉴的内容，支撑 README、答辩和后续设计取舍。

## 1. Hello-Agents Course

参考方向：

- Agent 基本范式。
- 工具调用。
- 多 Agent 协作。
- MCP。
- Agent 评估。
- 毕业设计项目组织方式。

本项目借鉴：

- 将复杂任务拆成多个专用 Agent。
- 使用工具和结构化输出支撑稳定流程。
- 设计 evaluation 规则，避免只做演示。

本项目不借鉴：

- 不直接复制课程代码。
- 不为了覆盖概念而堆功能。
- 不在 v0.1 强行实现所有 Agent 工程组件。

## 2. Resume2Job

本项目借鉴：

- 简历 + JD 匹配的 MVP 形态。
- 简历解析与岗位分析流程。
- 清晰的输入输出边界。

本项目不借鉴：

- 不只做单次问答工具。
- 不停留在一次性匹配分析。

原因：

JobAgent 希望后续扩展为持续求职工作台，包含岗位库、简历版本、面试准备和投递记录。

## 3. langgraph_jobsearch_assistant

本项目借鉴：

- LangGraph 工作流思想。
- 简历解析到岗位推荐再到报告生成的多步骤流程。
- Pydantic structured output。

本项目不借鉴：

- v0.1 不强制依赖外部搜索 API。
- v0.1 不把 LangGraph 放进第一优先级。

原因：

先用 mock 稳定数据流，等 schema 和流程稳定后再迁移到 LangGraph。

## 4. career-ops

本项目借鉴：

- 求职操作系统思路。
- 用户画像和长期记录。
- AI coding friendly 的项目组织方式。

本项目不借鉴：

- 不做过重配置系统。
- 不把项目变成纯 CLI 工具。

原因：

JobAgent 需要兼顾毕业设计展示、简历项目展示和后续产品化可能性，第一界面应容易演示。

## 5. AIHawk / ApplyPilot / 自动投递类项目

本项目借鉴：

- 求职流程可以拆成 Discover、Score、Tailor、Apply 等阶段。
- 浏览器自动化可以作为后期扩展方向。

本项目不借鉴：

- v0.1 不做自动投递。
- 不做招聘网站自动登录。
- 不处理验证码。
- 不把高风控自动化作为核心卖点。

原因：

自动投递涉及平台规则、账号风险和验证码处理，不适合作为第一阶段核心能力。
